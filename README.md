# Star Miner — Telegram Mini Game (MVP)

Аркада с виральной петлёй: рефералка (+200 обоим), стрик дней, ежедневное задание, рейтинг, бустеры.
Бэкенд и бот — на Node.js без единой зависимости (npm install не нужен).

## Что внутри

| Файл | Что делает |
|---|---|
| `game/index.html` | Вся игра: canvas-аркада, Telegram WebApp SDK, экраны меню/магазина/рейтинга |
| `server.js` | Сервер + бот в одном процессе: прогресс, рейтинг, стрик, рефералка, задания, валидация `initData`, long polling бота |
| `data.json` | База (создаётся сама при первом запуске) |

## Запуск локально (5 минут)

```bash
# Node.js 18+
DEMO_MODE=1 node server.js        # http://localhost:3000
# открой в браузере: http://localhost:3000/?uid=123&ref=999  (режим демо)
```

## Деплой (30 минут)

1. **Бот.** Напиши @BotFather → `/newbot` → придумай имя и username → забери токен вида `123456:ABC-...`.
2. **Репозиторий.** Создай аккаунт на github.com → New Repository (любое имя, публичный) → «uploading an existing file» → перетащи мышкой папки `game/` и файлы `server.js`, `README.md`.
3. **Хостинг.** Зайди на render.com → залогинься через GitHub → New → Web Service → выбери репозиторий → задай три переменные окружения:
   - `BOT_TOKEN` = токен из шага 1
   - `GAME_URL` = адрес, который выдаст Render после деплоя (вида `https://star-miner.onrender.com`)
   - `DEMO_MODE` = `0`
   
   Команда запуска: `node server.js`, план — бесплатный. После деплоя скопируй выданный HTTPS-URL и обнови в настройках сервиса переменную `GAME_URL` на него (сервис перезапустится за минуту).
   
   ⚠️ **Честное предупреждение про бесплатный Render:** он «засыпает» через 15 минут без входящего трафика, а long polling бота — это исходящий трафик, засыпание он не отменяет. Первый тап по кнопке «Играть» после паузы будет поднимать сервер ~30–50 секунд. Для теста на друзьях — терпимо. Для живой игры — переезжай на Railway (~$5/мес, не засыпает) или любой VPS за $4–6/мес: те же переменные, та же команда.
4. **Кнопка в меню (опционально).** В BotFather: `/mybots → Bot Settings → Menu Button` → URL = твой Render-адрес.

## Твои 5 поручений (на всё — один вечер)

- [ ] Создать бота через BotFather, получить токен
- [ ] Задеплоить на хостинг (по инструкции выше) — если застрянешь, кидай скрин, проведу по шагам
- [ ] Прогнать игру на телефоне через бота, погонять 3–5 забегов
- [ ] Позвать 10–20 знакомых по своей реф-ссылке — проверить, что бонус начисляется обоим
- [ ] Вставить канал в `taskGoBtn` (game/index.html, строка с `https://t.me/`) — сюда же потом придут спонсоры

## Первые метрики (проверяем через неделю)

| Метрика | Цель MVP | Если ниже — что чинить |
|---|---|---|
| D1 retention | > 40% | упростить первые волны, больше наград в начале |
| Доля сессий с приглашением | > 5% | увеличить бонус за друга, добавить карточку рекорда |
| Конверсия в покупку бустера | > 3% | подешевле первый апгрейд, пак «первый бустер −50%» |
